# Java Practicals

This repository contains Java practical programs from Practical 1 to Practical 14 for the Object-Oriented Programming (OOP) subject.

## Technologies Used
- Java
- JDK

## How to Run
1. Install Java JDK.
2. Open the practical folder in VS Code.
3. Open the terminal.
4. Compile the Java program:

   ```bash
   javac FileName.java
   ```

5. Run the program:

   ```bash
   java ClassName
   ```
